# notfukuda — 2026 A/W

A fictional fashion brand website and creative portfolio by Kyohei Fukuda.

18 items, generated fashion photography, interactive 3D product views, and the 20-second fashion film *AN ORDINARY DAY.*

Cart demo only. No payment, shipping, email delivery, or real customer account service.

## Hosting

Static HTML, CSS and JavaScript. Published by GitHub Pages from the `main` branch root. Local preview: `python3 -m http.server 8808`.

## Assets

Fashion images and film are AI-generated creative assets; 3D garments are fictional display models. They do not certify exact reproduction of real garments. Creative assets are not licensed for reuse. Three.js retains its MIT license in `objects/THREE-LICENSE.txt`.
